# 发布说明 · v0.4.1-local.1

> 莱茵音乐 · 第三方二次修改版（本地改造分支）。本版把上游 `RonaldDeng/Rhine-Music-Demo`
> **v0.4.1** 的新特性移植进 Windows 本地修改版。**非官方衍生作品**，上游未参与、未认可、不提供支持。

## 相对上一版（v0.3.0-local.4）新增

移植依据：上游 `v0.3.0 → v0.4.1` 共 193 个文件、约 2 万行改动（大头在 squash 提交 `c7da0b5`）。

**画面与交互**
- **总览缩略图模式**：拉远相机投影真实列名与数量，支持展开列、进入列、返回近景（按钮 / `V` 键）。
- **真实专辑列**：每张专辑只摆放一次，按歌手/流派/专辑名分列，各列独立居中；列内首尾夹取不循环。
- **保留每列浏览位置**：记住每列上次的专辑（可在设置中关闭，关闭后按画面实际深度选邻近专辑）。
- **滚轮 / 触控板导航**：在当前列内快速上下浏览。
- **行光照 / 行灯**：光带跟随目标排。
- **开场动画**：品牌片头与主界面共用左上品牌节点。
- **歌名裁切修复**：逐字形排版测量，长标题按完整字形截断。

**声音**
- **歌曲衔接三模式**：淡出但不淡入 / 淡出淡入 / 无缝播放（设置 → 声音）。音频后端保持本机
  libmpv（WASAPI），未采用上游的 macOS CoreAudio + FFmpeg 方案。

**设置与诊断**
- **光照实验室 / 动效设置**：设置面板新增「开发者调试模式」，可调光带与全局动画速度
  （0.25×–3×，实时生效）。
- **版本标识**：右下角显示 `V0.4.1`。

**保留的本地能力（较上游更全）**
- 专辑档案面板、详情⇄歌词小白条、歌词动效与 20 项歌词参数、歌词来源（同名 `.lrc` / 内嵌 SYLT/USLT）。
- 线上补录：QQ 音乐 / 网易云音乐 / 百度百科 / MusicBrainz / Discogs / Wikidata 六源，真实库覆盖率 76.9%。
- 图集脏矩形上传（262 kB 而非 21 MB）与两级字节预算缓存、封面文件头测尺寸、单飞详情解码。

## 已知差异与未完成项

- **音频后端未跟随上游**：上游 v0.4.1 的 FFmpeg 解码 + CoreAudio 输出为 macOS 专属；本版按既定决策
  保持本机 libmpv。上游的浏览器侧无缝/gapless 尚未接线（本版生产环境走 libmpv）。
- **QQ 音乐制作名单**：服务端接口已随 v0.4.1 源码就位，客户端查询界面尚未接线（制作人区块仍走 MusicBrainz）。
- **帧时序诊断（MusicFrameTiming）**：未接线。
- **上游检查脚本 3 项**因夹具/实现差异未通过（非缺陷）：`check-music-song-transition-ui`、
  `check-music-column-position`（夹具未定义本地设置面板的 `lyricsMarkup`）、`check-music-cover`
  （上游断言图集着色器夹取，本地图集用透明边距方案）。其余 19/21 项非联网检查通过。
- **未做真实 GPU 目视验证**：动画手感、总览/真实列观感、图集上传方向需你在装有 WebView2 的机器上确认。

## 启动

- 双击包根目录的 `RhineMusic.exe`（原生 WebView2 窗口，不需要浏览器）。
- 首次使用：界面 → 音乐库 → 选择本地音乐文件夹 → 扫描。
- 本版发布包已剥离私人数据（曲库索引、真实封面、私人路径）。

## 构建与验证

```bash
cd app
npx tsc --noEmit          # 退出码 0
npx vite build            # 126 模块
npm run check:music       # 本地验收脚本
```
