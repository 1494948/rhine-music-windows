# 使用说明 · Rhine Music 莱茵音乐（第三方二次修改版 · 本地）

本包是在 `RonaldDeng/Rhine-Music-Demo v0.3.0` 的 Windows 打包版之上做的本地改造，
**只在本机使用，不对外发布**。

---

## 一、怎么打开（推荐方式：双击 EXE）

1. **确认整个文件夹位置固定**（例如 `C:\RhineMusic`）。移动文件夹后请重新双击 EXE，不要只移动其中一部分。
2. **双击 `RhineMusic.exe`**。
   - 它会自己拉起内置的本地音乐服务与音频内核，然后打开一个**原生窗口**。
   - 不需要打开浏览器，不需要装 Node，不需要联网。
   - 首次启动约 3–10 秒（要读曲库索引）。

> **前提**：系统需要 Microsoft Edge WebView2 运行时。Windows 11 与大多数 Windows 10 已自带。
> 本机已确认安装（154.0.4258.53），可以直接双击。
> 若换到没有它的机器，EXE 会弹出「请安装 Microsoft Edge WebView2 运行时后重试」，
> 这时装一下运行时即可，或用下面的备用方式。

## 二、备用方式（没有 WebView2 时）

双击 **`启动音乐播放器.bat`**。

- 它直接启动本地服务，然后用**系统默认浏览器**打开 `http://127.0.0.1:5175/`。
- 功能完整（浏览、播放、歌词、专辑档案、线上补录都在），只是外壳换成了浏览器标签页。
- **关闭那个黑窗口就等于停止服务**，界面随之失效。

## 三、首次打开后做什么

界面默认已经在读 `music-data-v3` 里的曲库索引。如果看到的是演示封面而不是你的专辑：

1. 点左侧「音乐库」；
2. 在「音乐文件夹」里填写本机音乐目录的**绝对路径**（本包默认是 `C:\Users\徐梓烽\Music\Music`）；
3. 点「保存目录并扫描 ↗」，等扫描结束。

## 四、本次改造新增的东西，怎么用

### 1. 专辑详情页的小白条（详情 ⇄ 歌词）

打开任意专辑，顶部那条发光的小白条就是它：

| 操作 | 效果 |
|---|---|
| 鼠标移上去 | 白条变长变亮，光晕张开 |
| 单击 | **锁定**：待机浮动停在原地，白条变成实心标记；再点一次解锁 |
| 按住向下拖 | 专辑详情下滑淡出，歌词自上而下铺开；白条滑到歌词页下方 |
| 按住向上拖 | 完全反向回到详情 |
| 快速一甩 | 按甩动方向直接翻到底，不是"松手就归位" |
| 键盘 | `Tab` 聚焦后 `Enter`/`空格` 切换，`↑`/`↓` 取向，`Home`/`End` 直达两端 |

歌词只有在你**第一次开始拖动**时才会去解析和渲染，所以打开专辑本身不会变慢。

### 2. 专辑档案（发行背景 / 专辑意义）

在专辑详情页参数表下方，会看到一块 `ARCHIVE ／ 档案`：

- 右上角的标签说明这段内容的来源：
  - **人工补录** — 你自己写在 `app/content/album-archives.json` 里的内容（优先级最高）
  - **线上补录** — 刚刚从公开元数据源读到并附了出处的
  - **本地已核对** — 之前查询过、存在本机的介绍
  - **由本地数据推导** — 纯用本地信息算出来的事实（档案编号、时长分布、无损占比等）
- 每一条外部事实都会**连出处一起显示**，没有出处的不会被写成结论。

### 3. 线上补充详情与背景

两种触发方式：

- **单张**：在专辑详情页的档案块里点「线上补充详情与背景 ↗」；
- **整库**：打开「音乐库」面板，在「专辑详情与背景」一节点「逐张补充专辑详情与背景 ↗」。

行为说明（实测值）：

- 数据来源是 **MusicBrainz**（专辑类型、首次发行日期、匹配度）、**Apple Music 商店**（上架日期、流派、曲目数、版权）、**维基百科**（简介正文）。免密钥，音乐文件不会上传。
- 结果**缓存在本机 30 天**（`music-data-v3\album-online\`），再打开同一张专辑不再联网。
- 整库补录约 **2 秒/张**，79 张约 2.7 分钟。过程有进度显示，可以随时做别的。
- **补齐名称、歌手、年份会显著提高命中率**：标签不全的专辑匹配不上是正常的，界面会直说"未找到"，不会编内容。
- 某些来源在你当前网络下可能不可达（本机维基百科就是被 DNS 污染的状态）。这时界面会显示具体原因，并且**在 30 分钟内不再重复尝试那个来源**，避免每次打开专辑都白等。

## 五、数据与路径

| 项 | 位置 |
|---|---|
| 曲库数据（配置、索引、封面缓存、线上补录缓存） | 本包内 `music-data-v3\` |
| 播放服务日志 | `music-data-v3\player-service.log` |
| 音频内核日志 | `music-data-v3\mpv-config\mpv-playback.log` |
| 手工补录的专辑档案 | `app\content\album-archives.json` |

- 歌曲始终从**原始路径**读取，不复制、不改写标签。
- 服务只监听 `127.0.0.1`，不对外开端口。
- 想换数据目录：设环境变量 `MUSIC_DATA_DIR` 指向别处。
- 想换 Node 运行时：设环境变量 `RHINE_NODE`。

## 七、遇到问题

**双击 EXE 没有窗口？**
装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，或改用 `启动音乐播放器.bat`。

**界面能开但歌曲放不出来？**
音频走内置 `libmpv-2.dll`（WASAPI）。检查 `music-data-v3\mpv-config\mpv-playback.log` 里的
`current-ao=` 是否为 `wasapi`；也可以在设置里点「诊断播放内核」。

**端口 5175 被占用？**
备用方式固定用 5175，改 `.bat` 里的 `PORT` 即可。EXE 会自己从 5175 起顺延找空闲端口。

**界面卡顿？**
在设置里降低画质或关闭景深。跨列切换的卡顿已在本版修复（图集按需分配 + 封面离屏缩放）。

**线上补录一直说"未找到"？**
多半是本地标签不全（缺年份最常见）。补全 `发行年份`、`歌手` 后重试即可。
