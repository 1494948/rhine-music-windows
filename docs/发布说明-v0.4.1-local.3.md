# 发布说明 · v0.4.1-local.3

> 莱茵音乐 · 第三方二次修改版（本地改造分支）。在 `v0.4.1-local.2` 基础上
> **修复两个桌面端缺陷**，并按功能区域重整源码目录。
> **非官方衍生作品**，上游未参与、未认可、不提供支持。

## 相对 v0.4.1-local.2

### ① 修好：一首播放结束后不自动接下一首

以前会出现"歌放完了就停在那儿，不会自己往下走"。根因不在接歌逻辑，
而在**事件订阅根本没建立**：

桌面版由 WebView2 外壳驱动，外壳是在页面加载完成**之后**才异步注入原生播放通道的。
而 `MusicPlayer` 在构造那一刻就去检查"通道在不在"，不在就**跳过整个订阅**——
于是此后播放结束的信号（`eof`）发出来时，没有任何接收方，歌自然就停住了。

现在改为**先订阅、不等通道**，并新增"通道迟到"回调：等外壳真正注入后，
再补正后端状态。订阅在没有原生通道的普通浏览器里是惰性的，不产生额外开销。

### ② 修好：只有第一首能显示歌词，第二首起不显示

以前切到第二首歌词面板就空了。根因是**装载目标被二次推导覆盖**：
面板接到"切到这首"的指令后，转头又去问外壳"当前是哪首"，而切歌瞬间外壳还没同步，
问回来的仍是**上一首**，于是面板一直在装第一首。

现在改为**装谁就装哪首**：指令交过来的曲目优先，不再回头重新推导；
外壳一时取不到时也不会把面板留空。

### ③ 源码按功能区域重整（不改变任何行为）

`app/src` 从平铺的 99 个文件改为按功能分区，目的只有一个：
**改一个功能时，要动的文件都躺在同一个目录里。**

```
core/     通用底座：样式、动效、解密、质量设置、小工具
shelf/    唱片架三维场景：排布、相机、导航、灯光、档案、搜索、标题
viewer/   专辑查看器渲染管线：离屏、景深、锐化、玻璃揭示
boot/     启动动画
player/   播放内核：音频、libmpv 通道、接歌过渡、播放顺序
lyrics/   歌词：时间轴、面板组件、设置
```

新增 `app/src/README.md` 说明各区职责与新增文件的归属。
**这是一次纯结构调整，界面与行为与上一版完全一致。**
