## 一、这一版做了什么

这一版按 `docs/第三轮改造计划.md` 执行 **P0–P3**，三条主线：**换专辑卡顿彻底解决**、**歌词动效对齐 Apple Music 模型（AMLL）**、**歌词参数模块体验补全**；顺带修掉一个长期基线缺陷。

### 1. P1 · 换专辑卡顿：从"减少"到"消除"

上一轮的脏矩形上传只解决了"上传"这一半，剩下三个根因这次一起处理：

- **一次解码两次 + 解码了 16× 的像素**：旧逻辑先解码一次测尺寸、再解码一次出图，且按 1024 px 解一张只能显示 256 px 的瓦片。现在先读文件头拿到真实宽高（PNG/JPEG/GIF/BMP/WebP 五种格式），一次 `createImageBitmap` 直接重采样到位（瓦片 256、详情 1024）。
- **96 张 1024² 常驻位图 ≈ 402 MB**：改为**按字节预算的两级缓存**（瓦片 48 MB + 详情 40 MB），超预算按 LRU 逐出，GC 尖峰消失。
- **换专辑每步重建 1024² 纹理 + 标签画布**：改为**快照面复用池**（预分配、循环回收，关掉 mipmap）。
- **空闲预取**：首屏稳定后用 `requestIdleCallback` 按相邻顺序低优先级预热瓦片，把解码负担从"切换那一刻"挪到"没操作时"。
- **单飞详情解码**：连按 ↑/↓ 快速换专辑时，只解码最后停留的那一张，中间的全部丢弃（最多同时 2 张，而不是每步 1 张）。

### 2. P2 · 歌词动效：对齐 AMLL 模型

以画面为重、性能可舍（你已授权），逐字层从"一行一个裁剪百分比"升级为**逐字独立变换**：

- **逐字上浮 + 呼吸**：正在唱那一行拆成"逐字单元"（汉字逐字、拉丁按词），每个字一个 `--g`（0→1），未唱的字停在下方位并略大、唱到时落回原位。用 `transform` 实现，**不动字号/字重**，字形保持锐利、不重新光栅化。
- **行进入/退出**：未轮到的行停在下方位，越接近唱位越上移，形成"整叠滑上来"的纵深（`--ly-enter`）。
- **接手过冲**：新行接手时给一次轻微回弹（弹簧，约 340 ms，`--ly-settle`），落定后转入待机浮动。
- **间奏律动**：一句唱完、下一句还差一段时间时显示三个呼吸点（`--ly-dot-period` / `--ly-interlude-gap`），纯 CSS、零 JS 定时器。
- **每行 scale 重新评估**：你已授权性能可舍，高亮行放大改回参数可调（`--ly-active-scale`，默认 1.035），并只在唱行上加 `will-change`（不给 60 行整体加层）。

以上**每一项都能关、能调**（见 §3），没有"改不了的动效"。

### 3. P3 · 「歌词」参数模块体验补全

- **参数分组**：字号与版式 / 颜色与高亮 / 动效 / 时间，四组各带「复位本组」。
- **每项独立复位**：每个滑块右侧一个回位图标。
- **三套预设**：克制（现状）/ Apple Music / AMLL，一键套用。
- **导入 / 导出 JSON**：一键复制，粘贴恢复，导入自动钳位防坏值。
- **预览可选歌选行 + 跟随播放**：预览区可以选"用哪首歌的哪一句"，并支持"跟随播放"开关，跟随正在放的歌同步跳动。

参数从上一版的 13 项扩到 **20 项**，仍存在 `rhine-lyric-preferences`，即时生效并自动保存。

### 4. 顺手修掉的基线缺陷

`check-music-model.mjs` 此前长期失败（"day retains its frosted finish"）：白天主题把玻璃粗糙度抬到 0.48，但"检查（clarity）"路径却拿未主题化的 0.40 当锚点重新算，白天的雾面被检查态拉低。现在检查态按主题后的粗糙度为锚、且日照方向同样插值，白天在任何清晰度下都保住雾面。**这条基线缺陷已消除。**

## 三、怎么打开

1. 解压整个文件夹（**不要**只拖 `RhineMusic.exe`，它需要同目录的 `libmpv-2.dll`、`runtime\`、`app\`）。
2. 双击 `RhineMusic.exe`（首次启动约 3–10 秒）。
3. 没有 WebView2 时改用 `启动音乐播放器.bat`。

## 四、这一版仍需你确认的事

1. **换风格/换列/快速换专辑的手感**：是否已经"彻底解决"，还是仍能感知停顿。
2. **歌词逐字动效观感**：上浮/呼吸幅度、过冲、行进入是否合意（都在「设置 → 歌词 → 动效」可调）。
3. **间奏律动点**：无歌词的长间隔处是否出现、节奏是否舒服。
4. **封面方向**（上一版遗留）：封面是否显示成正确的专辑、有无镜像。

以上都需要真实 GPU 与你的屏，本机（无浏览器环境）无法自动校验。
