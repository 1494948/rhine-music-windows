# 发布说明 · v0.4.1-local.2

> 莱茵音乐 · 第三方二次修改版（本地改造分支）。在 `v0.4.1-local.1` 基础上补三项界面改动。
> **非官方衍生作品**，上游未参与、未认可、不提供支持。

## 相对 v0.4.1-local.1

**① 总览：列出当前流派的全部专辑名**
- 缩略图模式的标题区下方新增名单块，列出**当前那一列（流派）的全部专辑名**，
  两列排布、超高时底部渐隐，不抢滚轮（总览里滚轮仍然是切换流派）。
- 换流派时整块**先淡出、换好名单再淡入**，时长与缓动沿用总览进出的同一套参数
  （460/240 · 上移 · `cubic-bezier(.4,0,.2,1)`），不会出现闪字或跳行。
- 当前选中/正在播放的那张专辑名提亮；该流派没有专辑信息时整块收起，不留空框。
- 名单只在"当前列或选中专辑"变化时重算，不产生每帧字符串开销。

**② 详情封面更清晰**
- 打开专辑详情时的封面改用独立的大尺寸档：逻辑尺寸与解码上限从 1024 提到 **1536**
  （线性 1.5×，像素 2.25×）。原先 1024 在详情里会被场景放大，所以看着发虚。
- **图集与上传路径完全没动**（仍是 256px 瓦片 + 脏矩形上传），因此切换流派的速度不变。
- 详情档的缓存预算 40 → 64 MB，维持与之前相同的缓存条数，避免翻专辑时反复解码。

**③ 播放方式三合一按钮**
- 传输栏新增一个按钮，**顺序播放 / 随机播放 / 单曲循环**三态共用一体，
  点击循环切换，**只换字形、不改变按钮尺寸**，因此不会挤动左边的歌名与进度条。
- 切换动画与播放/暂停同一套（180ms、`scale(.7→1)`），并同样跟随"动效速度"设置。
- 非顺序播放时按钮常亮强调色，不点开也能看出当前不是默认方式。
- 播放器新增 `playMode`：自动续播（原生 eof、浏览器 ended）与手动下一首都按模式走；
  随机播放不会连着重放同一首，单曲循环重放当前这首。
